# KPI калькулятор AM

Веб-калькулятор KPI для отдела Account Management: расчет KPI AM и лидов помесячно и поквартально (выручка, KPI QBR, Health Score, eNPS, запуски), итог по бонусу и советы по каждому AM.

## Как пользоваться

1. Выберите период вверху: квартал - для бонуса, месяц - для промежуточного контроля.
2. Шаг «Данные»: загрузите выгрузки по блокам (Excel или CSV). Колонки сопоставляются автоматически, проекты - по названию и AM.
3. Шаг «Опрос по AM»: проверьте подставленные значения и внесите оценки лида.
4. Шаг «Результат»: таблица зон, итог по бонусу, KPI лида по команде, советы, выгрузка в Excel.

Пороги расчета согласованы и зафиксированы в коде (`TH_DEF`).

## Хранение данных

- Отдельно размещенная страница (этот репозиторий, GitHub Pages) хранит данные только в браузере пользователя (localStorage), по каждому периоду отдельно.
- Общее хранилище для РО и лидов, сводка по лидам и разбор с Claude работают только в версии калькулятора в claude.ai.

Документы обрабатываются в браузере и никуда не отправляются.
